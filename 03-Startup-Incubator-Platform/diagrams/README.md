# Startup Incubator Platform: Diagrams Index

This folder houses the structural and behavioral design diagrams for the Startup Incubator Platform.

All diagrams are created using **Mermaid.js**, which can be rendered directly in GitHub markdown.

## List of Diagrams in Master README:
1. **Startup Application Processing Sequence Diagram:** Shows the step-by-step workflow of file uploads to AWS S3, triggering OCR analysis and AI parameter extractions.
2. **Database ERD (Entity-Relationship Diagram):** Outlines the multi-tenant architecture, linking tenants, cohorts, startups, performance metrics, and pitch decks.

---

### Custom Rendering
To view these diagrams locally, use any Markdown viewer that supports Mermaid (e.g. VS Code Markdown Preview Enhanced) or copy the Mermaid code blocks from the [03-Startup-Incubator-Platform/README.md](../README.md) into the [Mermaid Live Editor](https://mermaid.live).
