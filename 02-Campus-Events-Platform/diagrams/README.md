# Campus Events Platform: Diagrams Index

This folder houses the structural and sequence diagrams for the Campus Events Platform.

All diagrams are created using **Mermaid.js**, which can be rendered directly in GitHub markdown.

## List of Diagrams in Master README:
1. **High-Concurrency Seating Reservation Sequence Diagram:** Outlines how Redis Redlock manages ticket claims and prevents double-booking.
2. **Database ERD (Entity-Relationship Diagram):** Maps the users, venues, events, bookings, tickets, and certificates tables.

---

### Custom Rendering
To view these diagrams locally, use any Markdown viewer that supports Mermaid (e.g. VS Code Markdown Preview Enhanced) or copy the Mermaid code blocks from the [02-Campus-Events-Platform/README.md](../README.md) into the [Mermaid Live Editor](https://mermaid.live).
